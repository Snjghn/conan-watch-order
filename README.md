# 코난 시청 순서

명탐정 코난, 괴도키드 1412, 닌자고, 블리치의 방영 순서와 시청 상태를 관리하는 개인용 웹 앱입니다.

## 실행

- 웹 앱: <https://snjghn.github.io/conan-watch-order/>
- iPhone에서는 Safari로 웹 앱을 연 뒤 `공유` > `홈 화면에 추가` > `추가`를 누르면 앱처럼 실행됩니다.

로그인하지 않은 시청 기록은 현재 브라우저의 기기에 저장됩니다. 같은 이메일로 로그인하면 코난, 괴도키드, 닌자고, 블리치의 O/X 기록이 PC와 iPhone에서 동기화됩니다.

## 데이터베이스

`supabase-schema.sql`은 시청 기록 테이블과 사용자별 Row Level Security 정책을 생성합니다. 브라우저에는 공개용 publishable key만 포함되며, 비밀 서버 키는 사용하지 않습니다.

## 블리치

일본 최초 공개일로 TVA·극장판·스페셜을 통합 정렬합니다. TVA 더빙은 제외하며 확인된 극장판은 자막판을 연결합니다. 구작 366화와 천년혈전 50화를 포함합니다. 회차별 재생 주소 대신 확인한 작품 페이지를 연결합니다. 한국어 공식 부제는 검증되지 않아 원제를 표시합니다. 제공 여부 미확인 작품은 링크 없이 표시합니다. [조사 출처와 범위](BLEACH_SOURCES.md)를 참고하세요.
